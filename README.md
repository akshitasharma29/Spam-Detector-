# Spamdetector

A machine learning-based Spam Detection System that classifies messages as spam or ham using Python, data analysis, and Power BI visualization.

🔹 Features

Spam vs Ham message classification

Data preprocessing and cleaning

Exploratory Data Analysis (EDA)

Word frequency analysis

Model performance evaluation

Interactive Power BI dashboard for visualization

Reports and metrics generation

🔹 Technologies Used

Python

Pandas & NumPy

Scikit-learn

Power BI

Machine Learning

Data Visualization
